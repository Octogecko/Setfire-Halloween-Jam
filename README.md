## 📖 Presentation
DressCop is a top down game developped for the game jam Setfire Halloween Jam. 
Play as the cop of the dress code and kick out whoever doesn't respect it.

## 🎮 How to play

| **Z, Q, S, D** to move in the game 
| **E** to inspect the guests
| **Left Click** kick'em up

You can play with a controller too by using de down button as E and the right button as left click


## 🚀 Installation & Setup
1. Download the latest version from the itch.io page
2. Extract the folder to your computer.
3. Launch the executable file:
   * **Windows**: "DressCop.exe"
